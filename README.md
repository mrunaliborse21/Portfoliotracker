📈 Stock Portfolio Tracker – Python

A simple Stock Portfolio Tracker developed using Python. This command-line application allows users to select stocks, enter the quantity they own, calculate the total investment value, and optionally save the portfolio summary to a text file.

🚀 Features
📊 Display available stocks and their prices
📋 Add stocks to a personal portfolio
🔢 Enter the number of shares owned
💰 Calculate the value of individual stock holdings
🧾 Generate a complete portfolio summary
📈 Calculate total investment value
⚠️ Validate stock symbols and quantity input
💾 Save portfolio summary to a .txt file
🖥️ Simple and interactive command-line interface
🛠️ Tech Stack
Python
Dictionary
Loops
Conditional Statements
Exception Handling
File Handling
String Manipulation
User Input
🧠 How It Works
The program stores stock symbols and their prices in a Python dictionary.
The user selects a stock from the available list.
The user enters the quantity of shares.
The selected stock and quantity are stored in the portfolio.
